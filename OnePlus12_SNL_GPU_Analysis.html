一秒尺度的交叉验证。 在主窗口内 59 个互不重叠的 1 s 均值上，总读取与纹理读取的 Pearson r 为 0.998，与纹理获取停顿为 0.959，与系统内存停顿为 0.954，与计算时间占比为 0.932。图元吞吐与顶点读取带宽的 r 为 0.971。相邻秒共享场景，且纹理读取本就与总读取有关；这些系数描述共同变化，因果归属要靠逐帧实验。

各硬件子系统给出的线索

着色器与指令

Shaders Busy 为 83.24%，Shaders Stalled 为 15.55%，ALU 容量利用率为 36.85%，ALU 工作时间为 40.99%。这些指标观察不同的活动条件。片元吞吐约 11.04 亿个/s，片元指令约 4705 亿条/s；以两个吞吐均值相除，约 426 条指令/片元。全精度 ALU、半精度 ALU、EFU 三列分别约 4555、204、192 亿条/s，各列计数定义需单独核对。片元占主导的区间更适合逐个比较 shader 指令、寄存器压力和 pass 耗时。

纹理、缓存与外部访存

纹理管线忙碌为 56.50%，纹理获取停顿为 18.40%。纹理 L1/L2 miss 分别为 28.92%/28.37%，I-cache miss 为 0.25%；三者各有自己的访问分母。最近点、线性、各向异性过滤报告占比分别约 57.2%、32.2%、9.8%。总读、纹理读、顶点读和 SP 读分别为 15.10、13.08、0.80 和 0.08 GB/s。主窗口有 10,938 个样本的纹理读取超过同一次总读取，故各来源只能比较量级与趋势，逐点相减求“其他带宽”会产生误导。

持续压力与短峰

总读取的原始样本中位数为 10.74 GB/s，P95 为 51.93 GB/s；写入均值为 3.92 GB/s，P95 为 14.83 GB/s。总线忙碌均值 18.55%，系统内存停顿均值 2.09%、样本 P95 为 13.60%。在 3,623 个系统内存停顿超过 10% 的样本中，3,616 个具备三个完整阶段字段，全部以计算阶段占比最高，另 7 个缺片元占比。这把排查范围缩小到了特定计算区间；是否限制帧速仍要测这些区间在慢帧中的实际耗时。

几何与顶点

主窗口平均每秒约 1.22 亿个裁剪前图元、1.23 亿个着色顶点、2.83 亿个复用顶点。顶点获取停顿均值 12.88%，样本 P95 为 51.16%。平凡剔除、裁剪的报告比例均值分别为 5.60%、0.17%，这些是采样比例的均值。顶点占比 ≥80% 的区间内，顶点读升至 3.69 GB/s，纹理获取停顿仅 0.06%。诊断这类 pass 应同时查看每帧图元数、顶点字节数、顶点复用和 binning/tiler 耗时。

频率、利用率与抢占

主窗口的每秒平均 Clocks / Second 落在 902.52–903.37 百万/s，GPU % Utilization 落在 42.025%–42.067%。同时 Shaders Busy 的 1 s 均值为 80.29%–90.70%。约 97.9% 的原始样本中，GPU % Utilization 与 100 × Clocks/s ÷ 2,147,483,647 相差不足 0.05 个百分点。这个经验关系提示应核实工具归一化分母；工作簿无法确认驱动公式。故 42% 不能换算成可用性能余量。主窗口 430 个样本的抢占率大于零；其中延迟中位数为 6.09 µs、P95 为 38.17 µs，最大 776.16 µs 出现在 44.817944 s。要解释卡顿，需要把该事件对齐同帧队列与调度。

显存、RTU 与采集起点

AH–AU 的 14 列共用 GPU Memory 表头，缺 PID、进程名和作用域。更新最频繁的 AH 和 AJ 峰值分别为 2.952 GiB（50.452 s）和 3.643 GiB（35.994 s）；到 86 s 前最新值分别约 0.151、0.840 GiB。两条轨迹均有回落，不能相加为应用占用，也不足以判断泄漏。RTU Busy、两项求交、BVH 访存停顿和延迟五列在全程 70,905 次周期记录里均为零，与 UL 的非光追负载描述一致。首条周期记录同时报出 64.95 亿 Clocks/s 和约 412 万次抢占/s，前一周期长度未知，保留原值作审计，排除于时间加权均值之外。

在华为设备上怎样验证

先记录华为机型、实际 GPU、系统与驱动版本、API、3DMark 版本和测试模式。UL 公布的标准 SNL 渲染分辨率为 2560×1440，场景以非光追方式渲染；Light 不使用异步计算，本次采集出现计算着色活动与此相容。本文件没有本次渲染设置和结果页，两端需分别确认。若两端无法运行同一构建、API 或渲染路径，可换成可复现的同镜头回放，注明差异。[UL 测试定义 · UL 引擎说明]

待验证的问题配对采集能区分原因的结果
差距首先出在哪个环节？同镜头、相同实际渲染像素数，记录帧边界、呈现、GPU 队列、提交和 pass 时间戳，同步 CPU 提交、GPU/DDR 频率及温度。先比较 GPU 帧耗时及各 pass 的 ms/frame。GPU 工作用时接近、帧间队列空档变长时，转查 CPU 提交、同步或帧率限制。
计算区间是否等待数据？在两端匹配类似 56–61 s 的同镜头、同 dispatch。采集外存读写字节/帧、纹理单元访问和数据等待；以设备是否支持为准。若同一计算 pass 变慢，同时读取字节/帧增加或数据等待上升，优先查访问局部性、缓存与资源格式。在可修改回放中只调整一次纹理 LOD 或资源布局，看该 pass 耗时是否随之下降。
片元或几何阶段是否变慢？选与 64–68 s 相同的内容，比对片元 pass 耗时、指令、着色像素，以及 binning/tiler 耗时、顶点数、裁剪前图元数。受控回放内单独降低渲染像素数，或单独降低几何 LOD。若只有前者明显缩短目标 pass，支持像素侧压力；若后者缩短 binning/顶点用时，支持几何侧压力。修改设置后的结果仅用于机制验证。
持续负载后是否受温控影响？相同环境和供电条件下，冷机与热稳态各重复至少 3 次；保留每轮温度、功耗（如可得）、CPU/GPU/DDR 频率和原始计时。对每次运行分别算同窗口的 P50/P95 帧耗时，再比较跨轮波动。若相同工作量、同 pass 随温升降频而持续变慢，才形成热限制证据。

对齐指标的分母。 在提供相应计数器的 Maleoon 设备上，用 GPU Duration 对齐 pass 耗时。Shader Core Active 的分母是 GPU 活动时间，EU Utilization、EU Stall by Data、Texture Unit Utilization 的分母是 Shader Core 活动时间。对 Mali 设备应重新枚举该代 GPU 支持的指标。比较带宽时，对同帧的 B/s 按时间积分得到 bytes/frame；再除以实际渲染像素数得到 bytes/pixel。对于不同架构，保留每侧计数口径，以时长及经核对的字节数作为共同参照。[华为性能计数器定义 · HiSmartPerf GPU 指标]

场景对齐优先于秒数对齐。 56 s 和 64 s 是本次采集的相对时间；另一设备的加载与执行速度会变化。用画面、帧 ID 或 pass 标签匹配相同内容。即使只有商业基准可运行，也可先完成固定设置的重复采集和结果页核对；可抓帧的应用再补单变量回放。原表没有 FPS、帧时间、分数、温度或功耗，因而无法从本次记录判定掉帧、能效或华为设备已有的瓶颈。[APA 帧处理时间 · APA 内存效率]

复算口径与局限

  1. 时间和权重。 对所有行，ts_ns − round(time_s × 10⁹) 恒为 19,074,834,464,925 ns。周期主轨由 C 列有效值识别，相邻周期中位间隔为 1.166 ms，P95 为 1.646 ms，最大 18.856 ms。将每个周期值视为描述截至该时间戳的上一段，按其与目标窗口的重叠时长加权，缺失列按自身有效时长重算分母。首个周期样本无前置区间，权重为零。主窗口内有 46,719 个时间戳；计入右端跨界区间后有 46,720 段贡献正权重。
  2. 缺项与重复。 54 个周期指标中，Textures / Fragment 有效 69,883 个（缺 1,022），% Time Shading Fragments 有效 70,841 个（缺 64）；其余周期列均为 70,905 个。主窗口缺项各 953、38。约 29.37% 的主窗口记录与前一条在全部 54 个字段上逐项相同。均值保留持续时间信息；这些毫秒采样不能当成独立帧或独立重复实验。
  3. 稳健性。 将权重改为后续间隔，主窗口平均读取由 15.10 变为 15.18 GB/s，Shaders Busy 由 83.24% 变为 83.26%；改成各行等权，则分别为 15.26 GB/s、84.25%。本报告的窗口均值口径一致；按阶段分组与相关系数用于描述同现，不作帧耗时回归。
  4. 百分比与比率。 主窗口 46,681 个三阶段字段齐全的样本中，有 28 个总和偏离 100% 超过 1 个百分点，最高达 213.23%。表中保留观测值，分类环节另设一致性条件。每片元、每顶点与缓存缺失率等比率的时长均值不等于所有操作的加权比率；低吞吐时分母小，单点最大值尤其敏感。源表没有事件级命中数或完整计数器公式。
  5. 研究范围。 官方规格列一加 12 为骁龙 8 Gen 3、Adreno 750。SNL 的场景属性取自 UL；本次实际软件版本、运行预设、驱动、各显存轨 PID、逐帧队列边界等均未随表导出。图中阶段名称、窗口和诊断假设属于本次分析。[一加 12 官方规格 · UL SNL 规范]
